# scrollstop

Writes and scores 2-second hooks for reels, covers, and posts — keeps only the top 3.

## Install

### Any Agent Skills host (`npx skills`)
```bash
npx skills add alexsmedile/scrollstop
```

### Claude Code Plugin
```bash
/plugin marketplace add alexsmedile/scrollstop
/plugin install scrollstop@scrollstop
```

### Portable Agent Plugin
Conforms to the [Agent Plugins](https://agent-plugins.org) standard (`plugin.json` + `skills/scrollstop/SKILL.md`) for Claude Code, Codex, Cursor, Antigravity, and VS Code.

## Usage
Invoke `/scrollstop` or ask your agent directly — see [`skills/scrollstop/SKILL.md`](skills/scrollstop/SKILL.md).
